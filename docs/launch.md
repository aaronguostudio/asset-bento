# Launch Notes

## Positioning

Asset Bento is an agent-first workflow for turning product design intent into brand-consistent, web-ready image asset packages.

It is not just a prompt library. It gives Codex and Claude Code a guided product asset workflow: brand intake, style presets, reusable profiles, structured briefs, image generation, export, metadata, alt text, and optional loading animation wrappers.

## Demo Prompt

```text
Help me make a premium but friendly loading asset for TinyNest.
```

## Short Announcement

I built Asset Bento: an open-source Codex / Claude Code skill and CLI for creating brand-consistent product image assets.

Instead of hand-writing prompts, you give the agent a product goal. It guides brand/style intake, creates reusable profiles and briefs, generates variations, then exports web-ready PNG/WebP packages with metadata and alt text.

GitHub: https://github.com/aaronguostudio/asset-bento

## Longer Thread

1. Product teams need small visual assets all the time: loading states, empty states, success states, feature cards, onboarding visuals, and icons.
2. One-off image prompts are hard to reuse. They drift from the brand and rarely export in a developer-friendly package.
3. Asset Bento treats image generation as a workflow: brand profile + style profile + asset brief + generated originals + exports + metadata.
4. It is agent-first. Codex or Claude Code can guide the user from a rough request to a generated asset package.
5. It ships with style presets like premium-minimal, soft-glass, friendly-clay, clean-saas-3d, and flat-product-icon.
6. It is open source and designed to be extended with more providers, profiles, presets, and review heuristics.
